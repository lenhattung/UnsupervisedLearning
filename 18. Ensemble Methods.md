## Phần 1: Decision Tree (Cây quyết định)

### 1.1. Ý tưởng

Decision Tree phân loại bằng chuỗi câu hỏi **if–else** trên các đặc trưng, tạo thành cấu trúc cây. Tại mỗi node, thuật toán chọn đặc trưng và ngưỡng sao cho **giảm impurity nhiều nhất**.

```
              [petal_length ≤ 2.45?]
              /                    \
           Yes                      No
      → setosa            [petal_width ≤ 1.75?]
                           /               \
                         Yes                No
                    → versicolor       → virginica
```

**Tiêu chí phân chia:**

| Tiêu chí | Công thức | Ghi chú |
|---|---|---|
| Gini (mặc định) | $1 - \sum_k p_k^2$ | Nhanh hơn |
| Entropy | $-\sum_k p_k \log_2 p_k$ | Nhạy hơn với lớp hiếm |

**Tham số kiểm soát overfitting:**

| Tham số | Ý nghĩa | Gợi ý |
|---|---|---|
| `max_depth` | Độ sâu tối đa | 3–10 |
| `min_samples_split` | Số mẫu tối thiểu để tách node | 5–20 |
| `min_samples_leaf` | Số mẫu tối thiểu tại leaf | 2–10 |
| `criterion` | Tiêu chí phân chia | `gini`, `entropy` |

## Phần 2: Bagging & Random Forest

### 2.1. Ý tưởng

Decision Tree đơn lẻ có **variance cao**. Giải pháp: kết hợp nhiều cây → **Ensemble methods**.

**Bagging (Bootstrap Aggregating):** huấn luyện B cây **độc lập** trên B tập bootstrap, rồi vote/trung bình.

```
Dữ liệu gốc
    ├── Bootstrap 1 → Tree 1 ─┐
    ├── Bootstrap 2 → Tree 2 ─┤→ Vote → Dự đoán cuối
    └── Bootstrap B → Tree B ─┘
```

**Random Forest = Bagging + random feature subset tại mỗi node**

Tại mỗi node chỉ xét $m = \sqrt{p}$ đặc trưng ngẫu nhiên → các cây **ít tương quan** hơn → ensemble hiệu quả hơn.

**Out-of-Bag (OOB):** ~36.8% mẫu không vào bootstrap → dùng làm validation mà không cần CV riêng.

| | Bagging | Random Forest |
|---|---|---|
| Đặc trưng mỗi node | Tất cả p | Ngẫu nhiên m < p |
| Tương quan giữa các cây | Cao hơn | Thấp hơn |
| Hiệu quả | Tốt | Tốt hơn |

### 2.2. So sánh cây đơn — Bagging — Random Forest

```python
X_train, X_test, y_train, y_test = train_test_split(
    X_bc, y_bc, test_size=0.2, stratify=y_bc, random_state=42
)

single_tree = DecisionTreeClassifier(random_state=42)
single_tree.fit(X_train, y_train)

bagging = BaggingClassifier(
    estimator=DecisionTreeClassifier(random_state=42),
    n_estimators=100, oob_score=True, random_state=42, n_jobs=-1
)
bagging.fit(X_train, y_train)

rf = RandomForestClassifier(
    n_estimators=100, oob_score=True, random_state=42, n_jobs=-1
)
rf.fit(X_train, y_train)

for name, model in [("Single Tree", single_tree), ("Bagging", bagging), ("Random Forest", rf)]:
    auc = roc_auc_score(y_test, model.predict_proba(X_test)[:, 1])
    oob = f" | OOB: {model.oob_score_:.4f}" if hasattr(model, "oob_score_") else ""
    print(f"AUC — {name:<16}: {auc:.4f}{oob}")
```

## Phần 3: Boosting

### 3.1. Ý tưởng

**Bagging** huấn luyện các mô hình song song, độc lập.  
**Boosting** huấn luyện tuần tự — mỗi mô hình sau **sửa lỗi** của mô hình trước.

```
Mô hình 1 → sai ở {A, B, C} → tăng trọng số {A, B, C}
Mô hình 2 → sai ở {D, E}   → tăng trọng số {D, E}
Mô hình 3 → ...
        ↓
Kết hợp có trọng số → Dự đoán cuối
```

**Ba thuật toán chính:**

| Thuật toán | Cơ chế | Đặc điểm |
|---|---|---|
| AdaBoost | Tăng trọng số mẫu sai | Đơn giản, nhạy với outlier |
| Gradient Boosting | Khớp với residual (phần dư) | Mạnh, cần tuning cẩn thận |
| XGBoost | Gradient Boosting + regularization | Nhanh, ít overfit hơn |

> 💡 **Quy tắc thực hành:** `learning_rate` nhỏ + `n_estimators` lớn thường tốt hơn, nhưng cần kết hợp early stopping để tránh chậm.

## Phần 4: Stacking

### 4.1. Ý tưởng

Bagging và Boosting kết hợp nhiều bản sao của *cùng một loại* mô hình.  
**Stacking** kết hợp các mô hình *khác nhau* bằng cách dùng một **meta-model** để học cách tổng hợp.

```
Dữ liệu
    ↓
┌──────────────────────────────────────┐
│   BASE LEARNERS (Level 0)            │
│  Logistic Reg | Random Forest | KNN  │
└─────┬─────────────┬──────────────────┘
      ↓             ↓             ↓
  pred_LR       pred_RF       pred_KNN
      └─────────────┴──────────────┘
                    ↓  (OOF predictions = features mới)
            META-MODEL (Level 1)
            Logistic Regression
                    ↓
              Dự đoán cuối
```

**Out-of-Fold (OOF):** meta-model phải được huấn luyện trên dự đoán mà base models chưa thấy, tránh data leakage.

```
Fold 1: base models học trên fold 2..K → predict fold 1
Fold 2: base models học trên fold 1,3..K → predict fold 2  (...)
→ Ghép lại thành OOF predictions → train meta-model
```

### 4.2. Stacking thủ công (OOF từng bước)

```python
X_train, X_test, y_train, y_test = train_test_split(
    X_bc, y_bc, test_size=0.2, stratify=y_bc, random_state=42
)

base_models = {
    "lr":  Pipeline([("sc", StandardScaler()), ("clf", LogisticRegression(max_iter=1000, random_state=42))]),
    "rf":  RandomForestClassifier(n_estimators=100, random_state=42, n_jobs=-1),
    "gb":  GradientBoostingClassifier(n_estimators=100, learning_rate=0.1, max_depth=3, random_state=42),
    "knn": Pipeline([("sc", StandardScaler()), ("clf", KNeighborsClassifier(n_neighbors=7))]),
}

cv = StratifiedKFold(n_splits=5, shuffle=True, random_state=42)

# Bước 1: OOF predictions trên tập train
oof_train = np.zeros((len(X_train), len(base_models)))
for j, (name, model) in enumerate(base_models.items()):
    oof_preds = cross_val_predict(model, X_train, y_train, cv=cv, method="predict_proba")[:, 1]
    oof_train[:, j] = oof_preds
    print(f"OOF AUC ({name}): {roc_auc_score(y_train, oof_preds):.4f}")

# Bước 2: Predictions trên tập test (huấn luyện lại trên toàn bộ train)
oof_test = np.zeros((len(X_test), len(base_models)))
for j, (name, model) in enumerate(base_models.items()):
    model.fit(X_train, y_train)
    oof_test[:, j] = model.predict_proba(X_test)[:, 1]

# Bước 3: Meta-model
meta = LogisticRegression(max_iter=1000, random_state=42)
meta.fit(oof_train, y_train)
print(f"\nAUC — Stacking (thủ công): {roc_auc_score(y_test, meta.predict_proba(oof_test)[:, 1]):.4f}")
```

### 4.3. Stacking với sklearn StackingClassifier

```python
estimators = [
    ("lr",  Pipeline([("sc", StandardScaler()), ("clf", LogisticRegression(max_iter=1000, random_state=42))])),
    ("rf",  RandomForestClassifier(n_estimators=100, random_state=42, n_jobs=-1)),
    ("gb",  GradientBoostingClassifier(n_estimators=100, learning_rate=0.1, max_depth=3, random_state=42)),
    ("knn", Pipeline([("sc", StandardScaler()), ("clf", KNeighborsClassifier(n_neighbors=7))])),
]

stack_clf = StackingClassifier(
    estimators=estimators,
    final_estimator=LogisticRegression(max_iter=1000, random_state=42),
    cv=5,                       # OOF tự động
    stack_method="predict_proba",
    passthrough=False,          # True = thêm X gốc vào meta-features
    n_jobs=-1
)
stack_clf.fit(X_train, y_train)
print(f"AUC — StackingClassifier: {roc_auc_score(y_test, stack_clf.predict_proba(X_test)[:, 1]):.4f}")
```

### 4.4. So sánh cuối cùng — tất cả phương pháp

```python

    "Decision Tree":     DecisionTreeClassifier(max_depth=5, random_state=42),

    "Stacking":          StackingClassifier(

```

### 4.5. Lưu ý thực tế

- **Base models cần đa dạng:** linear + tree-based + distance-based → sai theo cách khác nhau.
- **Meta-model nên đơn giản:** Logistic Regression, Ridge — tránh overfit trên OOF predictions.
- **Multi-level stacking:** lợi ích giảm dần, chi phí tăng nhanh — ít dùng trong thực tế.

## Tổng kết

| Phương pháp | Giảm | Cơ chế kết hợp | Đặc điểm nổi bật |
|---|---|---|---|
| Decision Tree | — | — | Đơn giản, dễ giải thích |
| Bagging | Variance | Song song, vote | Ổn định |
| Random Forest | Variance | Song song + random features | Thực dụng, ít tuning |
| AdaBoost | Bias | Tuần tự, weighted vote | Nhạy với outlier |
| Gradient Boosting | Bias | Tuần tự, fit residual | Mạnh, cần tuning |
| XGBoost | Bias | Tuần tự + regularization | Nhanh, early stopping |
| Stacking | Cả hai | Meta-model học cách kết hợp | Linh hoạt nhất |
